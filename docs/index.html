What moti does

Codegen, but you actually want to use it.

⬡
Wraps protoc, sanely
No more 14-flag invocations. moti reads a tiny config and runs protoc with the right plugins, paths, and includes — every time.
⊕
Pulls contracts from git
Reference proto/swagger files in any repo by URL + ref. moti fetches, caches, and version-pins them like a package manager.
◎
Multi-plugin output
Generate gRPC + HTTP gateway + OpenAPI + validators + your own protoc plugin — all in one pass, all configured per target.
⊞
Auto-installs binaries
Don't have protoc, protoc-gen-go, or your plugin of choice? moti detects, downloads, and pins the right versions for you.
⊡
Swagger → code
Point moti at an OpenAPI document and get typed clients/servers in any supported language — same workflow, same config.
⬕
CI-friendly
Deterministic output, locked plugin versions, cacheable artifacts. Drop moti in CI and never reproduce-codegen-on-Bob's-machine again.

Contracts as packages

Your proto files live in git.
moti treats them like dependencies.

Reference contracts by repo + ref + path. moti clones, caches, version-pins, and re-pulls on bump. No more copying .proto files between repos. No more drift between teams.

  • ✓Pin to tags, branches, or commit SHAs
  • ✓Pull from GitHub, GitLab, gitea, or any git remote
  • ✓Lockfile keeps the team in sync
  • ✓Cache is local — no central registry needed
